Leave the credential fields blank to keep the server’s current credentials.

The hub exchanges the calling user’s token for one scoped to this server (RFC 8693). Requires auth.type: jwt so the hub can validate who is calling.

Two legs: the hub swaps the caller’s assertion at your enterprise IdP for an ID-JAG, then redeems it at this backend’s own authorization server. Use this when the backend doesn’t trust your IdP directly. The IdP token endpoint and hub client credentials come from the on-behalf-of fields above.

Its issuer identifier, not the MCP server’s URL — this is what leg 1 asks the IdP for.

Delete server?
